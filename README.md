#软件实现技术期末作业

## 基于opencv实现一个qq小程序‘qq经典农场’的自动挂机脚本
需要实现的内容：
    1.启动按钮，点击后自动打开小程序
    2.定期重启，用户可输入定期重启的时间范围，程序每次从该范围内随机选择一个倒计时，倒计时到达后重启小程序
    3.小程序窗口定位，将小程序拖动到固定位置
    4.定期售卖果实，用户设置固定时间，每隔固定时间后，售卖果实。因为每次打开小程序后，小程序窗口位置固定，售卖过程可通过录入的鼠标动作用于售卖操作
    5.巡查功能，用户输入时间间隔，程序每次从该范围内随机选择一个倒计时，倒计时到达后进行一轮巡查，其中好友巡查与自家农场巡查交替进行
    6.自家农场巡查：基于计算机视觉技术匹配画面，判断当前农场是否可收获（项目会给出可收获时的游戏画面用于匹配判断）。若可收获则点击收获，则执行事先录入的另一套鼠标操作完成收获，铲除，新一轮种植操作
    7.好友偷菜，通过事先录入的鼠标动作用于打开好友列表。通过计算机视觉技术，判断好友列表最顶部是否可偷取（会给出可偷取时的游戏画面用于匹配片段）。若不可偷取，则好友巡查事件进入冷却倒计时，倒计时内不再进行好友巡查动作，该倒计时由用户给出。若可偷取，则执行事先录入的鼠标动作用于偷取，并返回自己的农场
